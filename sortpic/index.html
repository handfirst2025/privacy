개인정보처리방침

SortPic (com.handfirst.sortpic) · 개발자 FutureSoftLab · 시행일 2026년 10월 27일

SortPic 은 갤러리에 있는 명함·사업자등록증·여권·계약서·영수증 같은 서류 사진을 찾아 종류별로 모아 보여 주는 앱입니다. 사진과 사진 속 글자는 기기 안에서만 읽고 분류하며, 개발자 서버를 포함해 어디로도 보내지 않습니다. 회원가입·로그인이 없고, 원본 사진을 옮기거나 고치지 않습니다.

1. 앱이 처리하는 정보

  • 사진 — 사용자가 허용하면 기기 갤러리의 사진을 읽습니다. 사진은 기기 안의 Google ML Kit 글자 인식기(한글)로만 처리되며, 사진 파일이나 그 내용을 기기 밖으로 전송하지 않습니다.
  • 사진 속 글자(OCR 결과)와 분류 결과 — 검색과 서랍 분류를 위해 기기 안의 앱 데이터베이스에만 저장합니다. 서버로 보내지 않습니다.
  • 사진 촬영 위치(EXIF GPS) — 사용자가 앱에서 '장소별 보기'를 직접 켠 경우에만 읽습니다. 좌표를 나라·도시 이름으로 바꾸기 위해 안드로이드 기본 위치 변환 기능(Geocoder)을 쓰며, 이때 소수 둘째 자리(약 1km 단위)로 뭉갠 좌표 숫자만 Google 에 전송됩니다. 사진이나 글자는 함께 보내지 않습니다. 변환된 도시 이름은 기기 안에만 저장합니다. '장소별 보기'를 켜지 않으면 위치 정보는 전송되지 않습니다.

이름, 이메일, 전화번호, 연락처, 현재 위치(GPS), 광고 식별자(AAID)는 수집하지 않습니다.

2. Google ML Kit 가 수집하는 정보

글자 인식에 쓰는 Google ML Kit 은 기능 진단과 사용 통계를 위해 다음 정보를 Google 에 보냅니다 (Google ML Kit 데이터 공개).

  • 기기 정보(제조사, 모델, OS 버전), 앱 패키지명과 버전
  • 사용자나 기기를 식별하려는 목적이 아닌 설치별 식별자
  • 성능 지표(처리 시간), 기능 설정, 이벤트 종류, 오류 코드

사진이나 인식된 글자 자체는 이 정보에 포함되지 않습니다. ML Kit 은 이 정보를 HTTPS 로 암호화해 전송하며 제3자에게 넘기지 않습니다. 글자 인식 모델은 앱 안에 들어 있어 따로 내려받지 않습니다.

3. 요청하는 권한

  • READ_MEDIA_IMAGES (안드로이드 13 이상) / READ_EXTERNAL_STORAGE (12 이하) — 갤러리 사진을 읽어 서류를 찾는 데 씁니다. '시작하기'를 누르고 설명을 본 뒤에만 요청합니다.
  • READ_MEDIA_VISUAL_USER_SELECTED (안드로이드 14 이상) — 사용자가 '선택한 사진만 허용'을 고른 경우 그 사진만으로 동작하기 위해 씁니다.
  • ACCESS_MEDIA_LOCATION — 사진에 기록된 촬영 위치를 읽습니다. '장소별 보기'를 켤 때만 씁니다.
  • INTERNET, ACCESS_NETWORK_STATE — 좌표를 도시 이름으로 바꾸는 Geocoder 와 위 2항의 ML Kit 진단 전송에 필요합니다.

카메라, 마이크, 연락처, 현재 위치 권한과 '모든 파일 관리' 권한은 사용하지 않습니다. 사진을 삭제·수정·이동하지 않습니다.

4. 제3자 제공

광고 네트워크, 분석 도구, 소셜 로그인, 결제 모듈을 넣지 않았습니다. 위 1항의 Geocoder(뭉갠 좌표)와 2항의 Google ML Kit 진단 정보 외에는 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다.

5. 보관과 삭제

  • 앱이 저장하는 정보(글자 인식 결과, 분류, 도시 이름)는 모두 기기 안에 있습니다. 앱 데이터를 지우거나 앱을 삭제하면 사라지며, 원본 사진에는 아무 영향이 없습니다.
  • 개발자는 서버를 운영하지 않으므로 개발자가 보관하는 사용자 정보는 없습니다.
  • Geocoder 와 Google ML Kit 으로 전송된 정보는 Google 의 개인정보처리방침에 따라 처리됩니다.

6. 이용 대상

SortPic 은 업무 서류를 정리하려는 성인을 대상으로 합니다. 만 13세 미만 아동을 대상으로 하지 않으며, 알면서 아동의 개인정보를 수집하지 않습니다.

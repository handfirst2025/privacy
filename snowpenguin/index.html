개인정보처리방침

Snow Penguin (com.handfirst.snowpenguin) · 시행일 2026년 9월 7일 (광고 도입 반영)

이 게임은 계정을 만들지 않으며, 이름·연락처·위치 등 개인을 식별하는 정보를 수집하지 않습니다. 다만 화면 하단 배너 광고를 위해 Google AdMob이 광고 식별자를 사용합니다.

1. 수집하는 개인정보

Snow Penguin 자체는 사용자의 개인정보를 수집하지 않습니다. 이름, 이메일 주소, 전화번호, 연락처, 사진, 위치를 요구하지도 저장하지도 않습니다. 개발자는 사용자가 어떤 기록을 세웠는지조차 알지 못합니다. 게임 기록은 기기 밖으로 나가지 않습니다.

다만 게임에 포함된 광고를 게재하기 위해 Google AdMob이 다음 정보를 처리할 수 있습니다.

  • 광고 식별자(Advertising ID)
  • 기기 정보 및 대략적인 위치(IP 주소 기반)
  • 광고 노출·클릭 기록

이 정보는 앱 개발자가 아니라 Google이 직접 수집·처리하며, 개발자는 개별 사용자를 식별할 수 있는 형태로 열람하지 않습니다.

2. 계정 및 로그인

현재 버전에는 회원가입이나 로그인 기능이 없습니다. 기록은 기기 안에만 남고 서버로 올라가지 않으며, 사용자를 식별하거나 추적하지 않습니다.

3. 네트워크 통신

코스는 기기 안에서 절차적으로 생성되고, 게임 기능 자체는 인터넷 없이 완전하게 동작합니다. 현재 버전에서 네트워크는 광고를 불러올 때와 아래의 새 버전 확인에만 사용됩니다. 연결이 없으면 광고와 새 버전 안내만 표시되지 않고 게임은 그대로 이용할 수 있습니다.

타이틀 화면에서 game.fastmax.work 에 최신 버전 번호가 적힌 작은 파일을 요청합니다. 받아온 값을 6시간 동안 기기에 보관해 그 사이에는 다시 묻지 않으므로, 하루에 많아야 몇 차례입니다. 요청에는 앱의 패키지 이름만 담기며 개인정보·식별자·쿠키를 보내지 않습니다. 정상적으로 처리된 이 요청은 서버 접속 기록에 남지 않습니다(다만 서버 오류가 발생하면 원인을 찾기 위해 접속 정보가 잠시 기록될 수 있습니다). 새 버전이 있으면 앱 안에서 안내만 하고, 실제 설치는 사용자가 스토어에서 직접 진행합니다.

온라인 순위표처럼 통신이 필요한 기능을 나중에 추가할 경우, 어떤 정보가 어디로 전송되는지를 이 페이지에 먼저 반영한 뒤 해당 기능이 포함된 버전을 배포합니다.

4. 기기에 저장되는 정보

다음 정보가 브라우저 저장소(localStorage)를 통해 사용자의 기기 안에만 저장됩니다. 외부 서버로 전송되지 않습니다.

  • 최고 기록, 누적 거리, 레벨, 획득한 스킨 등 진행 상황
  • 고스트 주행 데이터 — 이전 주행의 위치 기록으로, 다음 판에서 자신과 경쟁하는 데 쓰입니다
  • 일일 도전 과제 진행도
  • 사운드, 조작, 화면 설정값
  • 마지막으로 새 버전을 확인한 시각과 그때 받은 버전 번호

앱을 삭제하면 이 정보도 함께 삭제됩니다. 서버 백업이 없으므로, 사용자가 직접 기록을 옮길 수 있도록 백업 내보내기 기능을 제공합니다. 이 기능은 사용자가 버튼을 눌렀을 때만 동작하며, 만들어진 백업 파일을 어디로 보낼지는 전적으로 사용자가 선택합니다. 개발자에게는 전송되지 않습니다.

5. 광고

이 게임은 화면 하단에 Google AdMob 배너 광고를 표시합니다. AdMob은 관련성 있는 광고를 제공하기 위해 광고 식별자를 사용합니다.

Google의 데이터 처리 방식은 Google의 파트너 사이트 정책에서 확인할 수 있습니다.

유럽경제지역(EEA)·영국·스위스 사용자에게는 광고를 불러오기 전에 동의 양식을 표시하며, 사용자가 선택한 내용에 따라 맞춤 광고 여부가 결정됩니다.

그 밖의 지역에서 맞춤 광고를 원하지 않으시면 기기 설정에서 끌 수 있습니다.
설정 → Google → 광고 → 광고 개인 최적화 선택 해제 (또는 광고 ID 삭제)

6. 제3자 제공

개발자가 사용자 정보를 제3자에게 판매하거나 제공하는 일은 없습니다. 광고 게재에 필요한 범위에서 Google AdMob이 위 1항의 정보를 처리합니다.

7. 아동의 개인정보

이 게임은 만 13세 이상을 대상으로 합니다. 개발자는 어떤 연령대의 사용자로부터도 개인정보를 수집하지 않으며, 광고 요청은 아동에게 부적합한 콘텐츠가 게재되지 않도록 전체 이용가(G) 등급으로 제한해 보냅니다.

8. 권한

이 게임은 카메라, 정확한 위치, 저장소, 연락처, 마이크 등 민감한 런타임 권한을 요청하지 않습니다. 기울기 센서도 사용하지 않습니다. 선언하는 권한은 인터넷 접근, 진동(충돌·착지 시 촉각 피드백), 광고 ID 사용 세 가지뿐이며 모두 설치 시점에 자동 부여되어 별도의 동의 창이 뜨지 않습니다.

9. 방침의 변경

이 방침이 변경될 경우 이 페이지에 갱신된 내용과 시행일을 게시합니다.

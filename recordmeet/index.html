개인정보처리방침

RecordMeet (Chrome 확장 프로그램) · 시행일 2026년 8월 31일

RecordMeet 는 어떠한 데이터도 수집하거나 외부로 전송하지 않습니다. 녹화된 영상과 음성은 사용자의 컴퓨터에만 저장됩니다.

1. 수집하는 개인정보

없습니다.

RecordMeet 는 개발자나 제3자에게 어떤 정보도 보내지 않습니다. 분석 도구(analytics), 추적 코드, 광고 SDK, 원격 서버 통신이 일절 포함되어 있지 않습니다. 계정이나 로그인 기능도 없습니다.

2. 녹화된 데이터의 처리

  • 녹화는 사용자의 브라우저 안에서만 이루어집니다.
  • 완성된 파일은 사용자 컴퓨터의 다운로드 폴더(다운로드/RecordMeet/)에 직접 저장됩니다.
  • 녹화 파일은 어떤 서버에도 업로드되지 않습니다.
  • 개발자는 사용자의 녹화 내용에 접근할 수 없습니다.

3. 무엇이 녹화되는지, 그리고 그 선택은 누가 하는지

녹화 대상은 사용자가 녹화를 시작할 때마다 직접 고릅니다.

  • 현재 탭 — 사용자가 확장 아이콘을 누른 그 탭의 화면과 소리만 녹화합니다. 다른 탭은 녹화되지 않습니다.
  • 전체 화면 — 크롬이 띄우는 화면 선택창에서 사용자가 직접 고른 대상과, 사용자가 "시스템 오디오도 공유"를 켠 경우의 시스템 소리를 녹화합니다.

전체 화면을 고르면 브라우저 밖의 화면까지 녹화될 수 있습니다. 다만 무엇을 공유할지는 전적으로 크롬의 화면 선택창에서 사용자가 정하며, 확장 프로그램이 대상을 임의로 고르거나 선택창 없이 화면을 가져올 수는 없습니다. 녹화 중에는 크롬이 자체 공유 표시줄을 띄워 공유 상태를 항상 알려 줍니다.

어느 경우든 녹화된 내용은 사용자의 컴퓨터를 벗어나지 않습니다.

4. 마이크 사용에 대하여

마이크는 사용자가 녹화 시작 버튼을 누른 뒤에만 활성화되며, 녹화를 중지하면 즉시 해제됩니다. 백그라운드에서 임의로 마이크를 켜지 않습니다.

마이크 권한을 거부해도 녹화 자체는 동작합니다. 이 경우 사용자 본인의 목소리만 파일에 포함되지 않습니다.

5. 권한을 사용하는 이유

권한사용 목적
tabCapture 사용자가 선택한 탭의 화면과 소리를 녹화하기 위해 사용합니다.
화면 공유 전체 화면 녹화를 위해 크롬의 화면 선택창을 띄웁니다. 사용자가 선택창에서 직접 고른 대상만 넘어옵니다.
마이크 접근 사용자 본인의 목소리를 녹음에 포함하기 위해 사용합니다. 탭 소리만으로는 본인 음성이 녹음되지 않습니다.
offscreen 녹화 처리를 수행할 백그라운드 문서를 만들기 위해 사용합니다.
downloads 완성된 녹화 파일을 사용자 컴퓨터에 저장하기 위해 사용합니다.
storage 선택한 녹화 품질 등 설정을 기억하기 위해 사용합니다. 설정값만 저장하며 녹화 내용은 저장하지 않습니다.
activeTab 사용자가 확장 아이콘을 클릭한 그 탭 하나만 녹화 대상으로 삼기 위해 사용합니다.
scripting 탭 녹화가 시작될 때 해당 탭에만 "녹화 중" 배지를 띄우기 위해 사용합니다. 페이지 내용을 읽거나 바꾸지 않습니다.

6. 기기에 저장되는 정보

다음 정보가 사용자의 브라우저 안에만 저장됩니다. 외부로 전송되지 않습니다.

  • 선택한 녹화 대상·품질·저장 형식 등 설정값
  • 현재 녹화 진행 상태

확장 프로그램을 삭제하면 이 정보도 함께 삭제됩니다.

7. 제3자 제공

개발자가 사용자 정보를 제3자에게 판매하거나 제공하는 일은 없습니다. 애초에 전송되는 정보 자체가 없습니다.

8. 아동의 개인정보

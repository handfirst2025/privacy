개인정보처리방침

Vocabee (com.handfirst.vocabee) · 개발자 FutureSoftLab · 시행일 2026년 11월 12일

Vocabee 는 AI 선생님과 대화하며 영어 단어장을 만들고, 카드를 넘기며 외우는 앱입니다. 회원가입이 없고, 기기 고유 ID 로 사용자를 구분합니다. 대화·단어장·학습 기록과 사용자가 보낸 단어장 사진은 개발자 서버에 저장되며, 답을 만들기 위해 Anthropic(Claude API)으로 전송됩니다. 광고와 분석 도구는 없습니다.

1. 수집하는 정보와 목적

  • 기기 ID — 앱이 처음 켜질 때 Android 기기 ID(앱 서명키·기기·사용자 조합마다 다른 값)를 서버로 보내 사용자를 구분합니다. 가입·로그인 대신 쓰는 값이며 이름이나 전화번호와 연결하지 않습니다.
  • 연결 코드 — 서버가 사용자마다 만드는 임의의 코드입니다. 다른 기기에 이 코드를 넣으면 같은 단어장을 함께 씁니다. 코드를 넣은 기기는 그 코드를 기기 안에 저장합니다.
  • 대화 내용 — AI 선생님과 주고받은 글을 서버에 저장해 대화 화면에 보여 주고, 다음 답변의 맥락으로 씁니다.
  • 단어장 — 단어장 이름, 단어와 뜻·품사·발음기호·예문·연상법, 사용자가 고친 내용.
  • 학습 기록 — 카드마다 "알아요/몰라요"·퀴즈 정답 여부와 시각, 다음 복습 날짜. 복습 순서를 정하고 진행 현황을 보여 주는 데 씁니다.
  • 사진 — 사용자가 대화에 보낸 단어장 사진은 서버에서 긴 변 1,600px 로 줄여 저장하고(원본은 버립니다), 대화 화면에 다시 보여 주며, 단어를 읽기 위해 AI 에 보냅니다. 사진의 위치 정보(EXIF)는 저장하지 않습니다. 사진은 사용자가 카메라로 찍거나 갤러리에서 고른 것만 받습니다.
  • 시간대 — "오늘" 복습 분량을 맞추기 위해 기기의 시간대(UTC 와의 차이)를 함께 보냅니다.

기기에만 있는 정보 — 발음 설정(자동 발음·빠르기·미국/영국), 연결 코드. 이것들은 서버로 보내지 않습니다. 발음은 기기의 음성 합성(TTS) 엔진이 읽어 주며, 앱은 읽을 단어·예문만 그 엔진에 넘깁니다.

개발자는 이메일, 전화번호, 주소록, 위치를 요구하지도 저장하지도 않습니다.

2. AI 처리 (Anthropic)

대화 답변과 단어 추가·수정은 Anthropic, PBC 의 Claude API 가 만듭니다. 대화 한 번마다 개발자 서버가 보낸 글·사진, 최근 대화, 단어장 목록과 가진 단어 목록, 학습 현황(오늘 복습 수 등)을 Anthropic 으로 보냅니다 (앱이 직접 보내지 않으며 기기 ID 는 보내지 않습니다). Anthropic 은 개발자의 요청을 처리하는 수탁자로서 이 데이터를 받으며, API 로 받은 데이터를 모델 학습에 쓰지 않고 자체 정책에 따라 보관 후 삭제합니다 — Anthropic 개인정보처리방침. Anthropic 서버는 미국 등 국외에 있으므로 위 정보는 국외로 전송됩니다.

3. 연상 그림

단어 카드의 연상 그림은 AI 가 쓴 영어 장면 설명(예: "돋보기로 시계 부품을 조립하는 장인")으로 개발자가 직접 운영하는 그림 생성 서버에서 만듭니다. 이 서버에는 단어·뜻·장면 설명만 보내며, 기기 ID·대화·사진은 보내지 않습니다. 외부 그림 생성 서비스는 쓰지 않습니다.

4. 요청하는 권한

  • INTERNET — 서버와 대화하고 단어장을 불러올 때 씁니다.

사진은 Android 의 기본 카메라 앱이나 사진 선택기를 통해 사용자가 고른 것만 받습니다. 앨범 전체 접근, 위치, 연락처, 마이크 권한은 사용하지 않습니다.

5. 제3자 제공

개발자가 사용자 정보를 판매하거나 마케팅 목적으로 제3자에게 제공하는 일은 없습니다. AI 처리를 위해 Anthropic 에(2항) 위 정보를 보냅니다. 광고, 분석 도구, 소셜 로그인, 결제 모듈은 넣지 않았습니다.

6. 보관 기간

대화·단어장·학습 기록·사진은 사용자가 앱을 쓰는 동안 서버(대한민국 AWS 서울 리전)에 보관하며, 삭제를 요청하면 지웁니다. 단어와 단어장은 앱에서 직접 지울 수 있고, 단어장을 지우면 그 안의 단어와 학습 기록이 함께 지워집니다. 앱을 지워도 서버의 기록은 남으며, 같은 기기에 다시 설치하거나 다른 기기에 연결 코드를 넣으면 이어집니다.

7. 데이터 삭제 요청

Vocabee(개발자 FutureSoftLab)에 저장된 내 정보를 전부 지우려면:

  • 앱의 단어장 › 설정 › 내 연결 코드 보기에서 연결 코드 앞 6자리와 대략의 사용 시작 날짜를 적어
  • handfirst2025@gmail.com 으로 "Vocabee 데이터 삭제 요청" 메일을 보내 주세요.

확인 후 30일 이내에 대화 내용, 사진, 단어장과 단어, 학습 기록, 연상 그림, 연결 코드, 기기 ID 를 모두 삭제하고 회신합니다. 삭제 후 따로 보관하는 정보는 없습니다. Anthropic 이 처리한 정보는 그 회사의 정책에 따라 보관·삭제됩니다.

8. 이용 대상

영어 단어를 공부하는 성인을 위한 앱입니다. 만 13세 미만 아동을 대상으로 하지 않습니다.

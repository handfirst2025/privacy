개인정보처리방침

식단톡 (com.handfirst.diet) · 개발자 FutureSoftLab · 시행일 2026년 11월 1일

식단톡은 밥 사진을 보내면 AI 가 음식과 칼로리를 알려 주고 식사 기록을 모아 주는 대화형 식단 앱입니다. 회원가입이 없고, 기기 고유 ID 로 사용자를 구분합니다. 보낸 사진·대화와 프로필(키·몸무게 등)은 개발자 서버에 저장되며, AI 분석을 위해 Anthropic(Claude API)으로 전송됩니다. 화면 상단 배너 광고를 위해 Google AdMob 이 광고 식별자 등 기기 정보를 처리합니다.

1. 수집하는 정보와 목적

  • 기기 ID — 앱이 처음 켜질 때 Android 기기 ID(앱 서명키·기기·사용자 조합마다 다른 값)를 서버로 보내 사용자를 구분합니다. 가입·로그인 대신 쓰는 값이며 이름이나 전화번호와 연결하지 않습니다.
  • 식사 사진 — 사용자가 직접 찍거나 앨범에서 고른 사진만 전송합니다. 서버에서 긴 변 1,280px 로 줄여 저장하고, 기록 화면에 다시 보여 주는 데 씁니다. 본인 기기에서만 열람할 수 있습니다.
  • 대화 내용 — 앱에서 주고받은 글과 AI 의 답을 서버에 저장해 대화 화면에 보여 주고, 다음 답변의 맥락으로 씁니다.
  • 식사 기록 — 날짜·끼니·음식·양·칼로리. 기록·통계 화면과 AI 조언에 씁니다.
  • 프로필(선택) — 별명, 성별, 출생연도, 키, 몸무게, 목표 몸무게, 목표. 대화 중 사용자가 말하거나 '나' 화면에서 입력한 경우에만 저장하며, 권장 칼로리 계산과 맞춤 조언에 씁니다. 말하지 않으면 비어 있습니다.

개발자는 이메일, 전화번호, 연락처, 정확한 위치를 요구하지도 저장하지도 않습니다. 이 앱의 칼로리·조언은 AI 의 추정치이며 의학적 진단이나 치료를 대신하지 않습니다.

2. AI 처리 (Anthropic)

음식 인식과 대화 답변은 Anthropic, PBC 의 Claude API 가 만듭니다. 대화 한 번마다 개발자 서버가 보낸 글·사진, 최근 대화, 프로필, 오늘 먹은 음식 요약을 Anthropic 으로 보냅니다(앱이 직접 보내지 않으며 기기 ID 는 보내지 않습니다). Anthropic 은 개발자의 요청을 처리하는 수탁자로서 이 데이터를 받으며, API 로 받은 데이터를 모델 학습에 쓰지 않고 자체 정책에 따라 보관 후 삭제합니다 — Anthropic 개인정보처리방침. Anthropic 서버는 미국 등 국외에 있으므로 위 정보는 국외로 전송됩니다.

3. 광고 (Google AdMob)

이 앱은 화면 상단에 Google AdMob 배너 광고를 표시합니다. 광고를 게재하기 위해 AdMob 이 다음 정보를 처리할 수 있습니다.

  • 광고 식별자(Advertising ID) 등 기기 식별자
  • 기기 정보(기종, 운영체제 버전 등)와 대략적인 위치(IP 주소 기반)
  • 광고 노출·클릭 기록
  • 광고 SDK 의 비정상 종료 로그 및 진단 정보

이 정보는 개발자가 아니라 Google 이 직접 수집·처리하며, 개발자 서버로 오지 않습니다. 사진·대화·프로필은 AdMob 에 제공하지 않습니다. Google 의 데이터 처리 방식은 Google 의 파트너 사이트 정책에서 확인할 수 있으며, Google 서버가 국외에 있으므로 국외로 전송될 수 있습니다. 유럽경제지역(EEA)·영국·스위스에서는 광고를 불러오기 전에 Google 의 동의 화면이 먼저 뜨고, 거부하면 비맞춤 광고만 표시됩니다. 맞춤 광고를 원하지 않으시면 기기 설정에서 끌 수 있습니다.
설정 → Google → 광고 → 광고 ID 삭제 (기기에 따라 "광고 개인 최적화 선택 해제")

앱에 인앱 결제는 없습니다.

4. 요청하는 권한

  • INTERNET — 서버와 대화하고 광고를 불러올 때 씁니다.
  • com.google.android.gms.permission.AD_ID — 광고 게재를 위해 AdMob 이 광고 식별자를 읽습니다.

사진은 Android 의 사진 선택기와 기본 카메라 앱을 통해 사용자가 고른 한 장만 받습니다. 앨범 전체 접근, 위치, 연락처, 마이크 권한은 사용하지 않습니다.

5. 제3자 제공

개발자가 사용자 정보를 판매하거나 마케팅 목적으로 제3자에게 제공하는 일은 없습니다. AI 처리를 위해 Anthropic 에(2항), 광고 게재를 위해 Google AdMob 이(3항) 위 정보를 처리합니다. 분석 도구, 소셜 로그인, 결제 모듈은 넣지 않았습니다.

6. 보관 기간

사진·대화·식사 기록·프로필은 사용자가 앱을 쓰는 동안 서버(대한민국 AWS 서울 리전)에 보관하며, 삭제를 요청하면 지웁니다. 개별 식사 기록은 앱의 기록 화면에서 직접 지울 수 있습니다. 앱을 지워도 서버의 기록은 남으며, 같은 기기에 다시 설치하면 이어집니다.

7. 데이터 삭제 요청

식단톡(개발자 FutureSoftLab)에 저장된 내 정보를 전부 지우려면:

  • 앱의 '나' 화면 맨 아래에 있는 기기 ID(앞 8자리)와 시작 날짜를 적어
  • handfirst2025@gmail.com 으로 "식단톡 데이터 삭제 요청" 메일을 보내 주세요.

확인 후 30일 이내에 프로필, 대화 내용, 식사 기록, 사진 파일, AI 조언 기록을 모두 삭제하고 회신합니다. 삭제 후 따로 보관하는 정보는 없습니다. Anthropic·Google 이 처리한 정보는 각 회사의 정책에 따라 보관·삭제됩니다.

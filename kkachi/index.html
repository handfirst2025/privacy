개인정보처리방침

까치 메신저 (com.handfirst.kkachi) · 개발자 SungMin Yun (handfirst) · 시행일 2026년 11월 12일

까치는 휴대폰 번호로 가입해 친구와 메시지·사진·파일을 주고받는 메신저입니다. 대화 내용과 첨부는 전달을 위해 운영자 서버에 저장되며, 광고·분석 도구는 쓰지 않습니다. '나와의 채팅'에 쓴 글만 메모 정리를 위해 AI(Anthropic Claude)가 처리합니다.

1. 수집하는 정보

  • 휴대폰 번호 — 가입·로그인 때 본인 확인(문자 인증번호)에 쓰고, 친구가 내 번호로 나를 친구로 추가할 수 있게 합니다. 내 번호는 나에게만 보이며 다른 사용자 화면에 표시되지 않습니다.
  • 이름 — 가입할 때 정하는 표시 이름(더보기에서 바꿀 수 있음). 이메일·비밀번호는 받지 않습니다. 로그인한 기기마다 인증 토큰이 발급되고, 서버에는 그 토큰의 해시값만 저장됩니다.
  • 인증 문자 발송 기록 — 인증번호를 요청한 번호, 요청한 IP 주소, 시각, 발송 결과. 인증번호 자체는 해시값으로만 저장하고 3분 뒤 무효가 됩니다.
  • 친구 목록 — 내가 번호로 추가한 친구.
  • 메시지와 첨부 — 사용자가 보낸 글, 사진, 파일(PDF·APK 등)과 보낸 시각. 사진은 보내기 전에 기기에서 크기를 줄이고 촬영 위치 등 사진 속 부가정보(EXIF)를 지웁니다. 파일 선택으로 보낸 파일은 원본 그대로 전송됩니다.
  • 메모 — 대화방에 딸린 메모와 '나와의 채팅'에서 AI가 정리한 메모.
  • AI 사용 기록 — '나와의 채팅' AI 처리 횟수와 사용한 토큰 수(하루 사용 한도 계산용). 글 내용은 이 기록에 남기지 않습니다.
  • 링크 미리보기 — 메시지에 인터넷 주소가 있으면 서버가 그 페이지의 제목·설명·대표 이미지 주소를 가져와 함께 저장합니다.
  • 읽음 정보 — 대화방에서 마지막으로 읽은 메시지(안 읽은 수 "1" 표시에 사용).
  • 알림 정보 — 앱의 Firebase 클라우드 메시징 등록 토큰, 웹 까치(PC 브라우저)의 웹 푸시 구독 정보, 대화방별 알림 끄기 설정.
  • 차단·신고 기록 — 사용자가 차단한 상대, 신고한 내용과 대상.
  • 서버 접속 기록 — 접속한 IP 주소, 시각, 요청 경로(웹 서버 로그).

연락처(주소록), 위치, 문자 메시지 내용, 광고 식별자(AAID), 사용 통계, 오류 보고서는 수집하지 않습니다. 인증번호 자동 입력은 키보드가 제안하는 기능을 쓰며, 앱이 문자를 읽지 않습니다.

2. 요청하는 권한

  • INTERNET — 메시지를 주고받기 위해 필요합니다.
  • POST_NOTIFICATIONS — 새 메시지 알림을 보여 주기 위해 요청합니다. 거부해도 앱은 동작합니다.

사진은 안드로이드 시스템 사진 선택기로, 파일은 시스템 파일 선택기로 사용자가 고른 것만 앱에 전달됩니다. 카메라는 시스템 카메라 앱을 불러 찍은 사진만 받습니다. 앱이 저장공간·카메라·연락처·문자 권한을 따로 요청하지 않습니다.

3. 이용 목적

  • 가입·로그인 때 본인 확인, 번호로 친구 추가
  • 메시지와 첨부를 대화 상대에게 전달하고, 다시 볼 수 있도록 보관
  • '나와의 채팅'에 쓴 글을 메모로 정리하고, 메모에 관한 질문에 답하기
  • 새 메시지 알림
  • 인증 문자 남용·신고 처리 등 부정 이용 방지
  • 서비스 장애 확인과 복구

4. 저장 위치와 보안

정보는 운영자가 관리하는 서버(Amazon Web Services 서울 리전)에 저장됩니다. 앱·웹과 서버 사이의 모든 통신은 HTTPS(TLS)로 암호화됩니다. 첨부 파일과 메모는 로그인한 해당 대화방 참여자만 볼 수 있습니다. 웹 까치는 로그인 상태를 자바스크립트가 읽을 수 없는 쿠키(HttpOnly)로 유지합니다. 다만 까치는 종단간 암호화를 제공하지 않으므로, 서버에 저장된 대화 내용은 운영자가 서비스 운영과 신고 처리를 위해 확인할 수 있습니다.

5. 처리 위탁과 국외 이전

까치는 아래 업체에 정보 처리를 맡깁니다. 그 밖에 광고 네트워크, 분석 도구, 소셜 로그인, 결제 모듈 등 제3자 SDK는 포함하지 않으며, 수집한 정보를 판매하거나 제3자에게 제공하지 않습니다.

  • Anthropic, PBC (미국) — '나와의 채팅' AI 메모.
    이전 항목: '나와의 채팅'에 쓴 글과 그 방의 최근 대화(최대 12개), 그 방의 메모 제목·내용. 이름·휴대폰 번호와 다른 대화방의 내용은 보내지 않습니다.
    이전 시기·방법: '나와의 채팅'에 글을 쓸 때마다 운영자 서버에서 암호화된 통신(HTTPS)으로 전송.
    보유 기간: Anthropic 의 상업용 API 정책에 따라 모델 학습에 쓰이지 않으며 일정 기간(현재 최대 30일) 뒤 삭제됩니다. (Anthropic 개인정보 처리방침)
    원하지 않으면 '나와의 채팅'에 글을 쓰지 않으면 됩니다 — 친구와의 대화는 AI로 보내지 않습니다.
  • Google LLC (미국) · Firebase 클라우드 메시징 — 앱 새 메시지 알림. 보낸 사람 이름, 대화방 이름, 메시지 미리보기(최대 500자)와 알림 토큰이 Google 서버를 거쳐 기기로 전달됩니다. (Firebase 개인정보 보호)
  • 브라우저 푸시 서비스 — 웹 까치 알림. 브라우저 제조사(Microsoft·Google 등)의 푸시 서버를 거치며, 알림 내용은 표준 웹 푸시 암호화(RFC 8291)로 암호화되어 그 서버는 내용을 읽을 수 없습니다.

인증 문자는 운영자의 휴대폰 회선으로 이동통신사를 통해 발송됩니다.

6. 보관 기간과 삭제

  • 계정 정보, 친구 목록, 메시지, 첨부, 메모, 차단·신고 기록은 계정이 유지되는 동안 보관합니다.
  • 인증 문자 발송 기록(번호·IP·시각)은 30일 뒤 자동으로 지웁니다. 인증번호는 3분 뒤 무효가 됩니다.
  • 로그아웃하면 그 기기의 로그인 토큰과 알림 토큰은 서버에서 지워집니다.
  • 서버 접속 기록은 14일이 지나면 자동으로 삭제됩니다.
  • 탈퇴: 앱 더보기 → 탈퇴하기에서 바로 할 수 있습니다. 휴대폰 번호, 로그인·알림 토큰, 친구 목록, 대화방 참여, '나와의 채팅'의 글·메모, AI 사용 기록을 즉시 지우고 이름은 '(알 수 없음)'으로 바꿉니다. 친구에게 보낸 메시지는 상대의 대화 기록으로 남으며 '(알 수 없음)'이 보낸 것으로 표시됩니다. 보낸 메시지·첨부까지 지우길 원하면 이메일로 요청해 주세요. (계정·데이터 삭제 방법) 상대방 기기에 이미 받아 저장한 파일은 삭제되지 않을 수 있습니다.

7. 신고와 차단

대화방 오른쪽 위 메뉴나 메시지를 길게 눌러 부적절한 내용과 사용자를 신고하고 차단할 수 있습니다. 신고는 운영자가 확인해 조치하며, 신고한 사실은 상대에게 알리지 않습니다. 차단한 사용자의 메시지와 알림은 더 이상 받지 않습니다.

8. AI 기능 안내

'나와의 채팅'의 메모 정리와 답변은 AI가 만든 것이라 틀리거나 빠진 내용이 있을 수 있습니다. 중요한 정보는 직접 확인해 주세요. AI 처리는 한 사람당 하루 100건까지입니다.

9. 아동 개인정보

까치는 만 14세 미만 아동을 대상으로 하지 않으며, 알면서 아동의 정보를 수집하지 않습니다.
